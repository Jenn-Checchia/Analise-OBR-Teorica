# Analise-OBR-Teorica
Análise das provas da OBR Teórica de 2007 à 2024 para provas, e 2023 à 2025 para participação de alunos e premiações.
Acesse o dashboard (painel de dados) do projeto e veja as principais análises!

Caso deseje replicar esse projeto (para alguma outra Olimpíada do conhecimento, por exemplo) ou compreender seu funcionamento, acesse:


— Agente Classificador: acesso ao colab que hospeda o Agente. 
Não se preocupe em mofificá-lo, essa é uma cópia para estudos, o dashboard e as planilhas oficiais não serão afetadas.

— Planilhas de Conferência: as tabelas que validaram o trabalho do Agente, antes e após as principais mofificações.

— Prompts usados: aqueles utilizados nesse trabalho para elaborar o gabarito e também embasar a Chain of Thought do Agente.
